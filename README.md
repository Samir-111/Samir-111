## 👨‍💻 Executive Summary

> *"Building seamless MERN stack applications powered by state-of-the-art Machine Learning & Artificial Intelligence."*

I am a **Computer Science & Engineering student (specializing in AI & ML)** and a passionate **MERN Stack Developer**. I specialize in creating full-stack web applications backed by modern databases, reactive user interfaces, microservices, and cutting-edge **Generative AI & RAG (Retrieval-Augmented Generation)** models.

### 🌟 Core Capabilities
- 🌐 **MERN Stack Development:** MongoDB, Express.js, React.js, Node.js REST APIs, Authentication & State Management.
- 🧠 **AI & Machine Learning:** Neural Networks, Computer Vision, Natural Language Processing, Feature Engineering.
- ⚡ **Generative AI & RAG:** Custom RAG Workflows, Vector Search (Pinecone), LangChain, Prompt Engineering.
- 📐 **Software Engineering:** Data Structures & Algorithms (DSA), System Design, Scalable Database Modeling.
